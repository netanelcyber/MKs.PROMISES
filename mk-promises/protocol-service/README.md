# קריאת פרוטוקולים באמצעות שרת Selenium

השירות קורא דפי ועדות מתוך דפדפן Chromium שמופעל ב־Selenium Grid, ומחזיר טקסט גלוי וקישורים אמיתיים למסמכים. בחירת מסמך PDF, DOCX או DOC מפעילה הורדה מוגבלת וחילוץ טקסט בצד השרת. השירות אינו מסכם את הדיון, אינו מפעיל LLM ואינו קובע אם הבטחה פוליטית קוימה.

צריך להפעיל את השירות ואת Selenium Grid כדי להשתמש בו. ה־APK הוא הלקוח; אין בו שרת Selenium מובנה. ההרצה אינה מופעלת אוטומטית בעקבות התקנת האפליקציה. ללא שרת מוגדר אפשר להמשיך להשתמש בשאר האפליקציה.

## הפעלה עם Docker Compose

מתוך תיקיית `mk-promises/protocol-service`:

```bash
export PROTOCOL_API_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
export PROTOCOL_ALLOWED_ORIGINS='http://localhost:8000'
docker compose up --build -d
docker compose ps
```

Compose מפעיל שני שירותים: קורא בכתובת `http://127.0.0.1:8788` ו־Grid ברשת הפנימית של Compose. יציאת 4444 של Grid אינה מפורסמת למחשב המארח או לאינטרנט. השרת ממתין לבדיקת המוכנות של Grid לפני הפעלת הקורא. אסימון הגישה מועבר לקורא כמשתנה סביבה ואינו נכתב ל־Dockerfile או לקובצי האתר.

תמונת הדפדפן היא `selenium/standalone-chromium:4.51.0-20261010`, תג מפורש של הפרויקט הרשמי. מוקצים לה `2gb` של זיכרון משותף, ועד שתי הפעלות דפדפן במקביל. התמונה של הקורא מתקינה גם `antiword` לקריאת קובצי DOC ישנים. [תגי התמונה הרשמית](https://hub.docker.com/r/selenium/standalone-chromium/tags) ו[הוראות Docker של Selenium](https://github.com/SeleniumHQ/docker-selenium) מתעדים את התמונות ואת בדיקת `/opt/bin/check-grid.sh`.

בדפדפן של האפליקציה, הגדירו את כתובת הבסיס `http://127.0.0.1:8788` ואת האסימון שבחרתם. יש להעתיק את האסימון מהסביבה המקומית שלכם; השירות אינו מחזיר אותו דרך API. אפשר להגיש את האתר לצורך פיתוח בחלון מסוף נוסף:

```bash
python3 -m http.server 8000 --directory ../web
```

פתחו את האתר דרך `http://localhost:8000`. כתובת זו תואמת בדיוק ל־Origin שהוגדר למעלה. אם משתמשים בכתובת אחרת, עדכנו את `PROTOCOL_ALLOWED_ORIGINS` והפעילו מחדש את שירות הקורא.

## שימוש בשרת Selenium קיים

נדרשים Python 3.10 ומעלה, Grid עם Chrome או Chromium, ושתי ספריות חילוץ המסמכים:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
export SELENIUM_URL='http://127.0.0.1:4444'
export PROTOCOL_ALLOWED_ORIGINS='http://localhost:8000'
python server.py
```

כתובת `SELENIUM_URL` נשארת בצד השרת. אפשר להשתמש גם בנתיב Grid קיים כגון `/wd/hub`. החיבור מיועד ל־Grid פרטי ואינו מקבל שם משתמש או סיסמה בתוך הכתובת. [מדריך Selenium Grid](https://www.selenium.dev/documentation/grid/getting_started/) מתאר את הפעלת השרת, ו[מפרט W3C WebDriver](https://www.w3.org/TR/webdriver/#endpoints) מגדיר את פקודות HTTP שבהן השירות משתמש.

בשרת Linux שאינו משתמש בתמונת Docker, התקינו `antiword` דרך מנהל החבילות אם נדרשת קריאת DOC ישן. ללא רכיב זה מוחזרת שגיאה מפורשת עבור DOC; קובצי PDF ו־DOCX עדיין נתמכים. הזיהוי נעשה לפי תוכן הקובץ: קובץ בכתובת שמסתיימת ב־`.doc` אך מכיל DOCX ייקרא באמצעות קורא DOCX.

## משתני סביבה

| משתנה | משמעות | ברירת מחדל |
| --- | --- | --- |
| `SELENIUM_URL` | כתובת שרת Grid שהמפעיל הגדיר | חובה |
| `PROTOCOL_HOST` | כתובת ההאזנה של הקורא | `127.0.0.1` |
| `PROTOCOL_PORT` | יציאת הקורא | `8788` |
| `PROTOCOL_API_TOKEN` | אסימון Bearer של הלקוח, עד 512 תווי ASCII גלויים | ריק, מותר רק בהאזנה מקומית |
| `PROTOCOL_ALLOWED_ORIGINS` | Origins מדויקים, מופרדים בפסיקים | ריק |

האזנה בכתובת שאינה loopback מחייבת אסימון. גם אישור מפורש ל־Origin בשם `null` מחייב אסימון. אין תמיכה ב־`*`. בקשה עם Origin שלא אושר נדחית לפני פתיחת דפדפן או הורדת מסמך.

## Android וכתובת HTTPS

גשר Android שולח את בקשת הקריאה ישירות לשירות, ללא כותרת Origin. לכן בדרך כלל אין צורך לאשר `null` עבור ה־APK. האפליקציה דורשת כתובת שירות HTTPS; הכתובת `127.0.0.1` בטלפון מתייחסת לטלפון עצמו.

כדי להשתמש בשירות מהמכשיר, חשפו **את קורא הפרוטוקולים** מאחורי reverse proxy עם תעודת HTTPS תקינה, והשאירו את Grid ברשת פרטית. הגדירו באפליקציה את כתובת הבסיס, לדוגמה `https://protocols.example.org`, ואת אסימון הגישה. אין להזין באפליקציה את כתובת Grid. דוגמת מיקום ב־Nginx, בתוך שרת HTTPS שכבר הוגדר:

```nginx
location = /api/protocols {
    client_max_body_size 32k;
    proxy_connect_timeout 5s;
    proxy_read_timeout 75s;
    proxy_pass http://127.0.0.1:8788;
}
```

ללקוח דפדפן המוגש ממקור HTTPS יש להוסיף את ה־Origin המדויק שלו. אישור `null` מיועד רק ללקוחות `file://` שתבחרו לאפשר במפורש; הוא אינו דרוש לגשר Android.

## בקשה ותשובה

הכתובת היחידה היא `POST /api/protocols`. יש לשלוח `Content-Type: application/json` וגוף עם שדה `url` בלבד. כאשר הוגדר אסימון, יש לשלוח `Authorization: Bearer <token>`.

```json
{
  "url": "https://main.knesset.gov.il/Activity/committees/pages/allcommitteeprotocols.aspx"
}
```

מותרים רק HTTPS, יציאה 443 או יציאה ברירת מחדל, ושם המתחם `knesset.gov.il` או תת־מתחם שלו. אין תמיכה בכתובות עם פרטי התחברות, בכתובות שרירותיות או בהעברת קוד JavaScript מהלקוח.

| שדה בתשובה | תוכן |
| --- | --- |
| `sourceUrl`, `finalUrl` | הכתובת המבוקשת והכתובת הסופית, לאחר אימות |
| `title` | כותרת הדף, מטא־נתוני המסמך או שם הקובץ; עד 300 תווים |
| `committee`, `date` | רק שורות מפורשות כגון `שם הוועדה:` ו־`תאריך:` במסמך מזוהה; אחרת `null` |
| `text` | טקסט שחולץ מהמקור, ללא סיכום או השלמה; עד 100,000 תווי Unicode |
| `kind` | `page`, `html`, `pdf`, `docx` או `doc` |
| `isProtocol` | האם התקבל טקסט עם סימני פרוטוקול מספקים; אינו אישור לתוכן או לקיום הבטחה |
| `truncated` | האם הטקסט או רשימת הקישורים קוצרו בשל מגבלה |
| `retrievedAt` | זמן הקריאה ב־UTC בפורמט ISO 8601 |
| `documents` | עד 50 קישורים שנמצאו בדף, עם `url`, `title`, `format` |
| `warnings` | עד 8 הערות על מגבלות הקריאה, סריקה או מסמך שלא זוהה |

`page` ו־`html` נקראים מתוך הטקסט הגלוי בדפדפן Selenium. `pdf` נקרא באמצעות `pypdf`, `docx` באמצעות `python-docx`, ו־`doc` באמצעות `antiword`. הטקסט מוחזר לפי סדר החילוץ של הקורא; ירידות שורה ותאים בטבלאות עשויים להיראות אחרת מהקובץ המקורי. השירות מאחד סימני סוף שורה ומחליף תווי בקרה לא תקינים בלבד, ללא ניסוח מחדש.

דף המכיל קישורים למסמכים מוחזר תמיד כ־`kind: "page"` ו־`isProtocol: false`. יש לבחור קישור לקריאת המסמך עצמו. טקסט של דף ניווט או רשימת דיונים אינו מוצג כגוף פרוטוקול.

שם קובץ רשמי הכולל `_ptv_` משמש רמז לזיהוי, אך נדרשים גם לפחות 250 תווים, כותרת פרוטוקול ממוספרת וסימן לישיבת ועדה. בשמות אחרים נדרשים בנוסף סעיפי נוכחות וסדר יום. מסמכי `_cs_bg_` הם מסמכי רקע ואינם מסומנים כפרוטוקול. זהו זיהוי שמרני: מקור תקין שקורא הטקסט לא הצליח לפענח היטב יכול להישאר לא מזוהה.

PDF ללא טקסט קריא מחזיר טקסט ריק, `isProtocol: false` והערה על הצורך ב־OCR. השירות אינו מבצע OCR ואינו ממציא טקסט. גם קובץ מוצפן או פגום אינו הופך לראיה. [תיעוד pypdf על חילוץ טקסט](https://pypdf.readthedocs.io/en/stable/user/extract-text.html) מסביר את ההבחנה בין שכבת טקסט לבין סריקה.

## גבולות זמן וגודל

הבקשה מוגבלת ל־32 KiB, כתובת המקור ל־4,096 תווים, ההורדה ל־12 MiB והתשובה ל־512 KiB. הקורא מבצע שתי קריאות במקביל לכל היותר. פעולות הרשת בודקות תקציב עבודה משותף של 65 שניות בין קריאות; לסגירת הפעלת Selenium מוקצות עד 5 שניות נוספות. חילוץ מסמכים רץ בתהליך נפרד, עם תקרת זמן של 25 שניות, ומגבלות זיכרון ו־CPU במערכות Unix.

לכל קריאת דף נפתחת הפעלת Chromium חדשה ללא שימוש בחשבון או בהפעלת דפדפן קיימת. נשלחת בקשת DELETE לסגירת ההפעלה גם כאשר הקריאה נכשלת. Grid מוגדר גם לפנות הפעלות לא פעילות לאחר 90 שניות, למקרה שבו התקשורת נותקה לפני שניתן היה לקבל או לסגור מזהה הפעלה.

הפניות הורדה נבדקות מחדש בכל שלב. הכתובת הסופית של דף Selenium נבדקת לפני חילוץ הטקסט. דף חסימה, HTTP 473, CAPTCHA או טופס התחברות מפסיקים את הקריאה; השירות אינו מנסה לעקוף אותם. קישורים ותוכן שלא נקראו אינם משמשים תחליף לפרוטוקול.

שגיאות מוחזרות בצורה הבאה, ללא הודעות פנימיות של Grid:

```json
{"error":{"code":"source_blocked","message":"המקור חסום, דורש התחברות או מציג בדיקת גישה. הקריאה הופסקה"}}
```

קודים שימושיים: `400` לבקשה לא תקינה, `401` לאסימון חסר או שגוי, `403` למקור או Origin חסום, `413` לחריגה מגודל, `415` לפורמט או קורא לא נתמכים, `422` למסמך שאינו קריא, `502` לשגיאת מקור או Grid, `503` לעומס או לתלות חסרה, ו־`504` לחריגה בזמן.

## בדיקות

משורש המאגר:

```bash
python3 -m pip install -r mk-promises/protocol-service/requirements.txt
python3 -m unittest discover -s mk-promises/protocol-service/tests -v
```

ברירת המחדל בודקת את פרוטוקול HTTP של Grid עם תשובות מדומות, חילוץ אמיתי ממסמכי בדיקה שנוצרים בזיכרון, סגירת הפעלות, CORS, אסימון ומגבלות גודל. בדיקות HTTP מקומיות פותחות שרת loopback בלבד; הן מדולגות במפורש בסביבה שאוסרת פתיחת שקע מקומי.

לאימות מול **Grid אמיתי שכבר פועל**, הגדירו `SELENIUM_TEST_URL` והריצו את אותה פקודת בדיקות:

```bash
SELENIUM_TEST_URL='http://127.0.0.1:4444' python3 -m unittest discover -s mk-promises/protocol-service/tests -v
```

בדיקה זו יוצרת הפעלה חדשה, פותחת `about:blank`, מזינה DOM קבוע של בדיקה, קוראת אותו, סוגרת את ההפעלה ומוודאת שמזהה ההפעלה כבר אינו פעיל. היא אינה פונה לאתר הכנסת ואינה משנה את רשימת הכתובות המותרות של API הייצור. כשהמשתנה אינו מוגדר הבדיקה מסומנת כמדולגת; אין בכך טענה שבוצעה קריאה חיה של פרוטוקול הכנסת.

קריאה חיה נבדקת בנפרד ורק לאחר הגדרת השרת, באמצעות קישור רשמי שהמשתמש בחר. דף החיפוש הרשמי הוא [פרוטוקולים של דיוני ועדות הכנסת](https://main.knesset.gov.il/Activity/committees/pages/allcommitteeprotocols.aspx). אם אתר הכנסת חוסם את מיקום השרת, מתקבלת שגיאת חסימה מפורשת.
