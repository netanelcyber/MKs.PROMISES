# מעקב הבטחות — חברי כנסת

אפליקציה בעברית (RTL) שמציגה, לכל חבר כנסת, את ההבטחות שלו מול מה שעשה בפועל.

## מה בפנים

- `web/` — האפליקציה עצמה: קובץ `index.html` יחיד, ללא תלויות. עובד בדפדפן הטלפון, ואפשר "להוסיף למסך הבית" (PWA).
- `android/` — מעטפת אנדרואיד (WebView) שארזת את `web/` ל-APK ומוסיפה גשר HTTP מקומי לאתר הכנסת, כדי לעקוף CORS.
- `.github/workflows/build-apk.yml` — בונה APK אוטומטית ב-GitHub.

## איך מקבלים APK

**א. GitHub (הכי פשוט, בלי להתקין כלום)**
1. פותחים ריפו חדש ב-GitHub ומעלים אליו את כל התיקייה הזו.
2. בלשונית Actions מפעילים את `Build APK`.
3. בסיום מורידים את `mk-promises-apk` ומתקינים את `app-debug.apk` בטלפון (נדרשת הרשאת "התקנה ממקורות לא ידועים").

**ב. Android Studio:** פותחים את התיקייה `android/` ובוחרים Build → Build APK(s).

**ג. PWABuilder:** מעלים את `web/` לאחסון סטטי עם HTTPS ומזינים את הכתובת ב-pwabuilder.com כדי לקבל חבילת אנדרואיד.

## איך משתמשים

1. מוסיפים חבר כנסת ידנית, או לוחצים "טעינה מהכנסת (ה-25)" לטעינת הרשימה מה-API הרשמי.
2. לכל חבר כנסת מוסיפים הבטחה עם קישור למקור (מצע, ראיון, נאום) ותאריך.
3. מוסיפים ראיות: הצעות חוק, הצבעות, נאומים. הצעות חוק אפשר לטעון מה-API ולשייך להבטחה.
4. קובעים סטטוס לכל הבטחה בנפרד. אין ציון מסכם.
5. לחברי כנסת חדשים: מסמנים "חדש בכנסת ה-26" ומתעדים "פעילות ציבורית קודמת" עם מקור, לפני ההשבעה.
6. תפריט "גיבוי" מייצא את הנתונים ל-JSON ומשחזר אותם.

## מגבלות ידועות

- הקוד נכתב בסביבה שאין בה Android SDK ואין גישה לאתר הכנסת. לכן **פרויקט האנדרואיד לא הודר** ו**קריאות ה-API של הכנסת לא נבדקו** מול השרת האמיתי. שמות הישויות והשדות (`KNS_PersonToPosition`, `KNS_Person`, `KNS_BillInitiator`, `KNS_Bill`) לקוחים מתיעוד ציבורי וייתכן שיידרשו תיקונים קטנים.
- נתוני הכנסת ה-26 לא יופיעו ב-API לפני שהכנסת תושבע. עד אז אפשר להזין חברי כנסת חדשים ידנית.
- חומת האש של הכנסת חוסמת שאילתות עם `;` ועם `$apply=aggregate`, והאפליקציה נמנעת מהן.
- הנתונים נשמרים מקומית במכשיר בלבד. אין שרת.
